# Obsidian Capture Workflow

这是一篇示范页，用来说明“临时想法如何进入知识库”。

## Purpose

把零散输入快速收集下来，再决定它应该去哪里。先收住线索，后面再分类。

## Trigger

适合以下场景：

- 突然想到一个观点
- 工作中遇到一个值得记录的问题
- 看到一段值得保存的资料
- 学习时遇到一个暂时还解释不清的概念

## Workflow

1. 先快速记录，不追求完整。
2. 给它一个临时标题，保留原始上下文。
3. 在每日或每周回顾时，判断它属于：
   - 项目笔记
   - Evergreen Note
   - 资源笔记
   - 待删除碎片
4. 如果值得长期保留，再补充定义、例子和关联链接。
5. 最后把它挂到对应的 MOC 下。

## Suggested Template

```md
---
title:
tags:
---

## Context

这条笔记来自什么场景？

## Core Idea

这条笔记真正想表达什么？

## Links

- [[相关主题]]
- [[相关项目]]
```

## Review Rule

- 当天快速记录
- 每周至少整理一次
- 没有长期价值的碎片直接删除
