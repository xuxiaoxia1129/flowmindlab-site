# Maps of Content

这些页面承担站点“地图”的职责，内容仓库放在具体笔记里。

按照 LYT / Ideaverse 的思路，MOC 的作用是：

- 定义一个主题的范围
- 组织核心问题与关键概念
- 连接项目、资源与具体笔记
- 帮助未来的自己更快找回上下文

## 使用原则

- MOC 负责导航与组织
- Note 负责具体内容
- Resource 负责外部资料
- Workflow 负责方法和流程
