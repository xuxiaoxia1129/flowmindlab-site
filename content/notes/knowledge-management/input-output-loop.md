# 输入驱动输出，输出倒逼输入

输入和输出要放在一个循环里看。

输入给输出提供材料，输出暴露输入中的缺口。两者分开看，很容易失衡。

## 输入是什么

输入包括读书、看文章、听课、看视频、观察案例、和别人交流。

输入的价值在于扩大材料库和问题库。没有持续输入，输出会越来越空。

## 输出是什么

输出包括笔记、文章、语音、视频、项目文档、公开页面。

输出的价值在于逼自己组织语言、暴露漏洞、形成反馈。

很多内容看起来懂了，一写就发现讲不清。这个卡住的地方，往往就是下一轮输入的入口。

## 两者如何互相推动

持续输入，会带来新的问题、新的概念和新的表达欲。

尝试输出，会发现自己哪里缺材料、哪里缺例子、哪里逻辑还不稳。

所以我更喜欢把输入和输出看成一个螺旋：

输入 -> 卡片 -> MOC -> 输出 -> 发现缺口 -> 再输入

## 我的比例

大多数时候，我会让输入多一点，输出少一点。

但输出不能长期缺位。没有输出，输入容易变成收藏和幻觉式成长。
